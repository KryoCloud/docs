# Introduction

KryoCloud is a modern, cloud-based Minecraft server management platform. It lets you deploy, manage, and scale Minecraft servers from a single dashboard — no manual server setup required.

## What is KryoCloud?

KryoCloud handles the infrastructure so you can focus on your community. It provides:

- **Instant deployments** — Spin up a new server in seconds
- **Auto-scaling** — Servers scale with your player count automatically
- **Plugin management** — Install and update plugins without restarting
- **Real-time monitoring** — CPU, RAM, and player stats at a glance
- **Backups** — Automatic daily backups with one-click restore

## How it works

KryoCloud runs on a distributed node network. When you create a server, KryoCloud picks the best node based on location and load, provisions the environment, and starts it. Everything is managed through the API or dashboard.

```
Your Dashboard → KryoCloud API → Node Network → Your Server
```
